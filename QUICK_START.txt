🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Docker won't start
Solution: Ensure Docker Desktop is running (check system tray)

Problem: Port already in use (3000, 5432, 8000)
Solution: netstat -ano | findstr :<PORT>
         taskkill /PID <PID> /F

Problem: Backend can't connect to database
Solution: Verify PostgreSQL is running
         docker ps | findstr postgres

Problem: CORS errors
Solution: Ensure backend is running on port 8000
         Check browser console for specific error
         Verify VITE_API_URL environment variable

Problem: WebSocket not connecting
Solution: Check "Live" indicator on Manager Dashboard
         Open DevTools → Network → WS filter
         Verify JWT token is valid (try logout/login)

See START_APPLICATION.md for more troubleshooting help!
